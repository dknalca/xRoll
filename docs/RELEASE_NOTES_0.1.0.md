# xRoll 0.1.0

Primera version tecnica del entrenador de finger drumming para macOS 12.

## Incluye

- Kit de seis sonidos y ocho ejercicios progresivos de hip hop.
- Entrada MIDI USB, teclado de repuesto y asistente de mapeo persistente.
- Vista previa, claqueta de entrada, carriles SpriteKit y puntuacion en tiempo real.
- Calibracion por perfil, SQLite para intentos y grafica de progreso.
- Empaquetador local para `xRoll.app`.

## Antes de publicar binarios

Se debe completar la validacion fisica de latencia y rendimiento, y confirmar
las licencias de los WAV. Las seis muestras incluidas son grabaciones originales
del autor bajo CC BY-SA 4.0. Por ello esta versión autoriza su distribución
junto con la aplicación.
