# Iniciación — De cero a tu primer groove

## Promesa

En 30–40 minutos, una persona sin experiencia puede preparar sus pads, comprender la notación y tocar un groove con bombo, caja y charles.

La ruta activa se concentra en cuatro mini-bloques completos. Las capas de la
pantalla de preparación permiten descomponer cada ritmo sin llenar el catálogo
de ejercicios de un solo pad.

## Objetivos

Al terminar, el usuario puede identificar tres voces, seguir cuatro pulsos, tocar negras y corcheas, ejecutar simultaneidades, mantener cuatro vueltas, interpretar temprano/tarde y repetir con ayudas reducidas.

el siguiente bloque sin exigir recorrer el despiece.

## Flujo común

Objetivo → escuchar → aislar → acompañar → practicar → diagnosticar → siguiente paso.

### I-00 — Conoce tu instrumento

No puntúa. La rejilla 4×4 responde en vivo, muestra sonido, nota, canal y posición. El usuario localiza bombo, caja y charles, toca libremente y confirma MIDI, audio y calibración. Termina con un resumen del layout.

### I-01 — Bombo y caja

```text
Cuenta  1 2 3 4
Bombo   X   X
Caja      X   X
```

Una vuelta de escucha, dos acompañadas y cuatro puntuadas. Los golpes extra de la primera vuelta se señalan sin penalizar. El feedback explica esperar a la línea o preparar el dedo.

### I-02 — Añade charles

```text
Cuenta  1 2 3 4
Bombo    X   X
Caja       X   X
Charles  X X X X
```

Enseña que el silencio forma parte del ritmo. Se distingue entre error de posición y error temporal. La última vuelta retira la iluminación anticipada.

### I-03 — Ritmo completo · vía rápida

```text
Cuenta  1 2 3 4
Bombo   X   X
Caja      X   X
```

Construcción por capas: usuario toca bombo con caja automática; después caja con bombo automático; finalmente ambos. Cierra la primera sesión con reproducción de eventos capturados.

### I-04 — Consolidar el groove

```text
Cuenta   1 2 3 4
Charles  X X X X
```

Introduce una voz regular. Observa aceleración, fatiga y dobles accidentales. La mano indicada es recomendación didáctica; MIDI no permite inferir qué mano física golpeó un único pad.

Mismo patrón; cambian las ayudas y se comprueba transferencia:
1. notación completa;
2. charles atenuado;
3. solo bombo y caja;
4. medio compás oculto;
5. solo rejilla y pulso;
6. notas completas para comprobar resincronización.

Se comparan resultado asistido y reducido.

## Ayudas

- **Completa:** nombres, forma/color, pad iluminado, cuenta, rejilla y dos compases.
- **Normal:** notas, forma/color y rejilla.
- **Reducida:** notas esenciales, menos anticipación y desaparición gradual.

## Intervenciones adaptativas

- No encuentra pad: abrir localizador 4×4.
- Golpea antes: dos golpes de demostración sin score.
- Dispersión alta: reducir de 68 a 62 BPM y acortar célula.
- Falla simultaneidad: separar parejas.
- No comprende corchea: volver a completar los `&`.

## Comunicación de score

Durante iniciación no se muestran score en vivo, rankings ni paneles densos. Se muestra dirección temporal, progreso de vueltas, una fortaleza y una prioridad.

Estados:
- completado: 50 %;
- sólido: 75 %;
- dominado: 85 % con sesgo y dispersión controlados;
- transferido: sólido con ayudas reducidas.
